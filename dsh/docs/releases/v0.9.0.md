# v0.9.0 — 真 PTY 终端 · 六种布局 · 标签跨格拖

> 这一版把与上游 `dsh-worktable@0.4.0` 的三处关键差距一次补掉：能跑交互式程序的终端、
> 顶行 / 三列 / 四格布局、跨窗格拖标签。没有新增配置项，装完重启即可。

## 1. 终端：从「命令模式」换成真 PTY

之前是「一条命令起一个进程 + 管道」：`cd`、流式回显、单条命令中断都对，但跑不了
`vim` / `top` / `ssh`，`Ctrl+C` 也进不到前台进程。现在走真伪终端：

- **原生模块借宿主自带的 node-pty**——不 npm 装、不现场编译。DSH 桌面端自己的终端就用它，
  借来的 ABI 与宿主进程完全一致；JS 从 `app.asar/dsh/node_modules/node-pty` 读，`.node` 自动落到
  `app.asar.unpacked`。
- **拿不到就降级，不报错**：`/term/open` 返回 `mode:'exec'`，界面退回老模式并在提示里写明原因，
  还给一个「再试一次 PTY」按钮。
- **渲染用 xterm.js**（`@xterm/xterm` + `addon-fit`，打进 bundle，无运行时依赖），配色跟随琥珀金主题。
- **不用 WebSocket**：输出用 `fetch` 读 NDJSON 长连接（先回放 backlog 再接实时流），
  输入攒 10ms 批量 POST，尺寸变化 140ms 防抖后报 `cols/rows`。
- **切标签页不杀 shell**：会话 id 固定为 `wt-pty-<项目id>`，切走只是卸载 xterm，切回来重挂并回放
  最近 240KB 输出；点「重启」才 kill + 重开。
- **运行配置 ▶ 跟着改**：有 PTY 时命令直接打进交互式 shell（输出看得见），■ 发 `Ctrl+C`
  而不是无条件杀进程树。

## 2. 布局：3 种 → 6 种，支持三格 / 四格

| 预设 | 格子 | 形态 |
|---|---|---|
| ▭ 单窗格 | 1 | 一次一个窗口 |
| ◫ 左右两栏 | 2 | 拖动条 20%–80%，双击回 50/50 |
| ⬓ 上下两栏 | 2 | 同上 |
| ▤ 上一下二 | 3 | 顶行通栏 + 下面并排两栏，横竖各一条分割线 |
| ▥ 三列 | 3 | 三栏并排，两条分割线可拖（末列保底 15%） |
| ▦ 四格 | 4 | 2×2，一条行分割 + 两行列分割 |

切到多格时，空格子会自动挑「还没被别格占用」的标签页；关掉正被某格用着的标签页时，
那一格会自动换一个顶上；只剩一个标签页时仍然自动退回单窗格。

## 3. 标签页跨格拖

把标签拖到另一格 → 两格内容**互换**（标签页总数不变），落点那一格亮一圈琥珀色内描边。
拖回同一格不动作；拖到只剩一格时不会误触发。

## 升级 / 安装

先完整退出 DSH，再执行（把 `<你的 DSH 安装目录>` 换成本机实际路径）：

```powershell
& "<你的 DSH 安装目录>\resources\runtime\cli\bin\dsh.cmd" plugin --profile desktop add "https://github.com/nscn6fdx44-crypto/dsh-worktable/releases/download/v0.9.0/trae-usage-worktable-0.9.0.tgz"
```

不想碰命令行：看仓库里的 [INSTALL.md](https://github.com/nscn6fdx44-crypto/dsh-worktable/blob/dsh-plugin/INSTALL.md)。

## 验证

- 离线自测：host **140** + client **518** 断言全绿（新增 9 条 host 的 PTY 降级契约、22 条 client 的
  三格/四格/跨格拖断言）。
- 打包后 `sha256` 与本地一致；构建产物 `node --check` 通过。
- **真机 PTY 需要重启 DSH 后才生效**：重启后看终端工具条的 `PTY` 徽标是否点亮，
  再按 README「验收清单」第 6 / 6b / 6c 条走一遍（`python` 进 REPL、`Ctrl+C` 退 REPL 但 shell 还在、切走再切回输出还在）。

## 已知边界

- Windows 走 ConPTY，个别旧系统版本可能丢输出（`useConpty` 已默认打开）。
- backlog 只保留输出字节，不保留完整滚动状态：切回来是「最近 240KB 重放」，不是逐像素复原。
- 多格布局里「第二条分割线」在三列下按比例归一，末列最低 15%，不会挤成一条缝。
