# v0.10.0 — 真正的 Git 管理：登录 GitHub、上传、克隆、提交、推送、版本管理

> 0.9.0 之前版本控制只有「看得见、动不了」：能看分支和改动，暂存/提交/推送一律得去终端。
> 这一版把整条链路做进工作台，并且把 GitHub 账号接进来。

## 新增：⑂ 源代码管理窗

工作区新增标签页（和文件管理器平级），一屏走完「看改动 → 暂存 → 提交 → 推」：

| 区 | 内容 |
|---|---|
| 头部 | 当前分支、`↑ahead ↓behind`、取回 / 拉取 / 推送 / 刷新 |
| 提交区 | 说明输入 + 「提交」「提交并推送」「全部暂存」 |
| 三段改动 | 暂存的 / 未暂存的 / 未跟踪，行内 `＋` 暂存、`－` 取消暂存、`↺` 丢弃 |
| diff | 点行在底部展开，增删上色，截断 3000 行，二进制只报标记 |
| 历史 | 最近 20 条，点击看该提交的 diff，「回退」= `reset --soft` |
| 分支 / 标签 / 远程 | 切换、新建并切换、删除、检出远程分支（建跟踪分支，不落 detached）、打标签、看 origin |

破坏性动作（丢弃改动、删分支、删标签、回退）都是**两步确认**：第一下按钮变成「确认?」，4 秒不动自动撤销。

## 新增：GitHub 账号

- **不登录也能用**：本地提交、推送照常走系统 git 凭据。
- **自动识别**：打开窗格时依次探测「插件保存的令牌 → `GH_TOKEN`/`GITHUB_TOKEN` → `gh auth token` → `git credential fill`」，
  本机已经用 Git Credential Manager 登录过的，直接显示账号，不用粘任何东西。
- **粘令牌登录**：`ghp_` / `github_pat_`，存 `~/.dsh/worktable-github.json`（0600）。
  可选「同时写进系统凭据管理器」，让内置终端里的 `git push` 也免密。
- **令牌不进 argv**：只通过环境变量 `WT_GH_TOKEN` + 一次性 `credential.helper` 交给 git；`/gh/status` 只回账号信息，从不回令牌。

## 新增：上传仓库

点「上传仓库」填名字、选私有/公开，然后四步：

1. `git init`（已是仓库则跳过，分支默认 `main`）
2. 没有任何提交时自动「初始提交」
3. 在 GitHub 建同名仓库并设为 `origin`（已有 origin 则沿用，不重复建）
4. `push -u origin <当前分支>`

每步都回显在结果弹窗里，失败会把 git 的原话贴出来（不吞错）。

## 新增：克隆仓库

总览顶栏「⑂ 克隆」，或新建项目窗里。支持：

- `owner/repo` 简写（自动补成 `https://github.com/owner/repo.git`）
- 私有仓库（自动带令牌）
- `--depth 1` 浅克隆、只取某个分支
- NDJSON 实时进度（`Receiving objects: 68%` 这种会滚出来）
- 克隆完自动建成项目并打开

目标目录要求：可以不存在，但父目录必须存在且落在可写白名单内（用户目录 / 工作目录 / 已注册项目）；已存在且非空直接拒。

## 修复：路径沙箱认不出 8.3 短名

`C:\Users\JINSHU~1\...` 这类短路径会被判成「越界」，因为它和 realpath 出来的长路径字符串对不上。
现在 `canonicalize` 优先用 `realpathSync.native`（Windows 上会还原短名），写操作不再误拒。

## 证书：三条退让，默认不降级

Windows 上 schannel 的吊销检查连不上时（`CRYPT_E_NO_REVOCATION_CHECK`），git 会整条命令失败。
现在的顺序是：

1. 原样跑
2. 失败且是证书类错误 → 加 `-c http.schannelCheckRevoke=false`（只关吊销检查）
3. 还失败 → **只有用户勾了「跳过证书校验」** 才加 `-c http.sslVerify=false`

开关在克隆窗和「分支 → 远程」里，勾一次记在 `wt.git.insecure`，推送/拉取/克隆一起生效。
默认关闭，界面上写明了它是什么。

## 接口

`POST /git` 变成本机 git 的唯一入口（op 白名单：status / log / branches / tags / remotes / diff /
stage / unstage / discard / commit / fetch / pull / push / checkout / branch / tag / reset / init / remote），
另加 `POST /git/clone`（NDJSON 进度）与 `/gh/status`、`/gh/login`、`/gh/logout`、`/gh/repos`、`/gh/create`、`/gh/upload`。

`status` 现在一次带回 log / branches / tags / remotes，窗格刷新不再打四个请求。

## 安装

先**完整退出 DSH**（托盘 → 退出），再在 PowerShell 里：

```powershell
# 网上下载装
& "<你的 DSH 安装目录>\resources\runtime\cli\bin\dsh.cmd" plugin --profile desktop add "https://github.com/nscn6fdx44-crypto/dsh-worktable/releases/download/v0.10.0/trae-usage-worktable-0.10.0.tgz"

# 或先下载再装本地文件
& "<你的 DSH 安装目录>\resources\runtime\cli\bin\dsh.cmd" plugin --profile desktop add "<你下载的 tgz 绝对路径>"
```

不想碰命令行看 [INSTALL.md](https://github.com/nscn6fdx44-crypto/dsh-worktable/blob/dsh-plugin/INSTALL.md)。
