# v0.10.12 — 编辑器回退为独立窗格（撤销 0.10.10 / 0.10.11 的停靠改动）

> 发布：2026-10-20 · 门禁：host **189** + client **643** 全通过

## 为什么回退

0.10.10 把编辑器塞进「文件管理器右侧面板」，0.10.11 又改成「工作台右侧停靠栏」。
两次改动都让编辑器失去了「独立窗格」的身份，实际操作上反而更难用（和文件列表抢宽度、切换窗格时容易误解）。

本版按需求**回退到 0.10.9 的形态**：编辑器是一个独立窗格（标签页），点文件就在新标签页里打开。

## 回退内容（`git revert` 了 0.10.10 与 0.10.11 两个提交）

- `PANE_TABS` 重新包含 **◆ 编辑器**；`RETIRED_TAB_KINDS` 清空（不再自动清掉 editor 标签页）；
- 移除 `.ws-editor-dock`（工作台右侧停靠栏）、`.fx-editor-dock`（文件管理器右侧面板）与 `EditorDock` 组件；
- 移除 `wt.editorW` / `editorDockWidth()` / `setEditorDockWidth()` 这套只服务停靠栏的记忆；
- `openFile()`：文本 / 代码 / Markdown → **打开 editor 标签页**；媒体 → 媒体窗；`.html` → 自定义窗口；
- 编辑器本体（文件名 / 未保存标记 / 大小 / 👁 Markdown·代码预览 / 保存 Ctrl+S / 系统打开 / 状态条）保持不变。

## 保留（这些和位置无关，没回退）

- 0.10.9 的「关窗格回初始态」`resetPaneState()`；
- 0.10.9 的「关工作台彻底」`closeWorkbench()`：清 `chatDropHover` / `menu` / `modal` / `tabMenu`，
  `releaseDock()` + `forceClearHostMargin()` 还宿主边距；
- 拖文件/网页到顶栏发到对话、媒体窗、产物回挂等全部功能。

## 安装

```powershell
# 先完整退出 DSH，装完手动重开
& "D:\dsh\resources\runtime\cli\bin\dsh.cmd" plugin --profile desktop add "https://github.com/nscn6fdx44-crypto/dsh-worktable/releases/download/v0.10.12/trae-usage-worktable-0.10.12.tgz"
```

## 升级后自检

1. `/api/trae-worktable/health` 的 `version` = `0.10.12`；
2. 文件管理器双击 `.md` → **新开一个「◆ 编辑器」标签页**（不是右侧面板、也不是停靠栏）；
3. 编辑器里改一行 Ctrl+S；关掉该标签页再双击，内容应是空的初始态；
4. 「＋ 窗口」菜单里应能看到 **◆ 编辑器**。
