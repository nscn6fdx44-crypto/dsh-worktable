# v0.8.53 — 文件 / 网页可拖到会话

> 发布日期：2026-10-19 · 提交 `f2f518a` · 门禁：host **131** + client **496** 全通过

## 新增

### 拖文件到对话
- **文件管理器**每一行可拖：拖到工作台**顶栏**松手 → 该文件的绝对路径被填进右侧对话输入框；
- 工具条新增 **「→ 对话」**：发送当前选中的文件（没有选中时发送当前目录路径）；
- 拖拽同时写入 `application/x-wt-file`、`text/plain` 与 `file:///` 的 `text/uri-list` —— 拖给浏览器、资源管理器等外部程序也能识别。

### 拖网页到对话
- **浏览器地址栏**可拖：拖到顶栏松手 → 当前网址（带页面标题）填进对话；
- 工具条新增 **「💬」**：一键把当前网页发到对话。

### 顶栏就是放置区
- 项目工作区与总览的标题栏整条都是投放目标；拖动经过时高亮并提示「松手 → 填进对话输入框」；
- 接收端四级回退解析：自定义类型 → `File.path`（Electron）→ `text/uri-list`（含 `file://` 还原成 Windows 路径）→ `text/plain`。

### 落文格式（只填输入框，不自动发送）
```
【文件】arch.png
C:\projects\demo\docs\arch.png

【网页】示例站
https://example.com/x
```
