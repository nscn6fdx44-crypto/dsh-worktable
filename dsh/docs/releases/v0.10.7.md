# v0.10.7 — 拖一个 `.html` 进窗格，不再被宿主的弹窗挡住

## 修的是什么

0.10.6 里「自定义窗口放本地网页」只有三个入口：左栏 `＋ 网页文件`、编辑态的「选文件…」、文件管理器右键
「在自定义窗口里打开」。**把 `.html` 直接从资源管理器拖进窗格**这条最顺手的路没有接 —— 窗格没挂 `drop`
处理器，事件就一路冒到窗口上，被宿主自己的拖放处理器接走，弹出它自己的窗（要不要加进对话 / 要不要打开
这个文件那类），把工作台整个挡住，还挡住得挺彻底。

## 怎么修的

事件就地吃掉，再自己接住文件：

- **自定义窗格**（`panes.js`）：根节点挂 `onDragOver` / `onDragLeave` / `onDrop`。认出是系统文件拖拽
  （`types` 里有 `Files`，或是带 `files` 的 `text/uri-list`，或本插件自己的 `application/x-wt-file`）就
  `preventDefault()` + `stopPropagation()`，`dropEffect = 'copy'`，同时整块亮起虚线框 + 「松手 → 放进这个窗格」。
- 只收 `.html` / `.htm` / `.xhtml`；落进来就变成 `kind:'file'` 草稿（**没起名字就用文件名主干顶上**）并
  直接切到预览，`/asset` 托管，同目录 css / js / 图片照常加载。非网页文件给一句提示，不落库、不改草稿。
- 有未保存改动时**只提示、不弹确认框**：`toast('当前改动还没保存 —— 先点「保存」，再来拖')`。
- **整块工作区兜底**（`overlay.js`）：没被具体窗格接住的系统文件，`.pane-main` 也吃掉 —— 拖的是 `.html`
  就直接落进自定义窗口，其它类型给一句「网页拖进「自定义」窗格」。一律 `preventDefault` + `stopPropagation`，
  宿主那边收不到事件就不会弹窗。**只认系统文件**（`Files` / 带 files 的 uri-list），拖标签页换格子那套不受影响。

## 顺手修的

- 新建草稿不再被标成「未保存」：原来 `dirty` 只比较字段，草稿和上一条已保存记录必然不等，于是刚点「＋」
  就亮红、切窗口还会弹确认框。现在要求 `draft.id === item.id` 才算改脏。
- `overlay.js` 之前调 `toast()` 却没 import（只在「切对话失败」那条路径上炸）—— 一并不上了。

## 测试

- host **188** 不变；client **585 → 594**：拖 html 落成 `kind:'file'` 草稿（含文件名顶名、直接进预览）、
  拖非网页文件拦下且不改草稿、拖标签页经过窗格不抢事件、`.pane-main` 兜底吃掉系统文件拖拽。

## 怎么验

**纯客户端改动，不用重启 DSH**：刷新工作台页面即可。从资源管理器把一个 `.html` 拖进「自定义」窗格 ——
应看到虚线高亮 +「松手 → 放进这个窗格」，松手后直接出现预览，不再有任何宿主弹窗。
