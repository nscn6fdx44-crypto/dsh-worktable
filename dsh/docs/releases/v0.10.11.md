# v0.10.11 — 编辑器停靠在工作台**右侧**（不是标签页）

> 发布：2026-10-20 · 门禁：host **189** + client **644** 全通过

## 这次改了什么

编辑器不再是一个标签页，也不再挤在文件管理器内部——它现在是**工作台右侧的一条停靠栏**：

- 打开任意文本 / 代码 / Markdown（文件管理器里双击、编辑器空态填路径、拖文件进窗格）→ 右侧滑出编辑器停靠栏；
- 停靠栏默认 **460px**，左边缘把手可拖动调宽（280 ~ 1200px，**双击复位 460**），宽度记在 `wt.editorW`，重开还在；
- 左侧标签页（终端 / 浏览器 / 文件管理器 / 自定义 …）**不切走、不重开**，编辑器和当前窗格并排；
- 停靠栏自己的 `✕` 关掉即清空内容，左侧窗格保持原状；
- `PANE_TABS` 里没有 `editor`，老版本存下的 editor 标签页由 `stripRetiredTabs()` 自动清掉。

## 边界

- 停靠栏宽度上限 1200px / 62%，不会把左侧窗格挤没；
- 关闭时若有未保存改动会 `confirm` 一次（`closeEditor(force)` 可跳过）；
- 大文件仍按 `/fs/read` 的窗口预览（`truncated` 会提示「只读了前一段」），要全文用「系统打开」。

## 安装

```powershell
# 先完整退出 DSH，装完手动重开
& "D:\dsh\resources\runtime\cli\bin\dsh.cmd" plugin --profile desktop add "https://github.com/nscn6fdx44-crypto/dsh-worktable/releases/download/v0.10.11/trae-usage-worktable-0.10.11.tgz"
```

## 升级后自检

1. `/api/trae-worktable/health` 的 `version` = `0.10.11`；
2. 进项目 → 文件管理器 → 双击一个 `.md`：**右侧**出现编辑器，左侧列表还在；
3. 拖停靠栏左边缘改宽度，双击复位；关掉停靠栏再双击文件，宽度应保留；
4. 「＋ 窗口」菜单里**不该再有「编辑器」**。
