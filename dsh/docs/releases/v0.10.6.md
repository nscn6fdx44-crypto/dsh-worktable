# v0.10.6 — 编辑器下架 · 标签条能左右滑 · 自定义窗口能放本地 html

> 2026-10-20 · 界面清理 + 功能补强 · 自测 host **188** + client **585** 全通过

## 一句话

工作台不再自带编辑器（和宿主 / 系统默认程序重复）；项目内标签条溢出时能左右滑；
自定义窗口可以直接指向磁盘上的一个 `.html`，相对路径的 css / js / 图片会跟着加载。

## ① 删掉「编辑器」窗格

它的功能和宿主自带的编辑器、系统默认程序完全重叠，还会带来「同一个文件两处可改」的歧义。
**整块下架**：标签定义、`store.editor` 状态机、`openFile` 的文本通道、行号栏、保存守卫、
`Ctrl+S`、预览 / 高亮切换，全部移除（约 240 行客户端代码）。

文件按类型分流：

| 类型 | 去哪 |
|---|---|
| 图片 / PDF / 音视频 | 媒体窗（`/fs/raw`，本来就是这个通道） |
| `.html` / `.htm` / `.xhtml` | 自定义窗口（新能力，见 ③） |
| 其余文本 / 代码 / 日志 | 系统默认程序（`POST /fs/open`） |

**老数据迁移**：`wt.ui.v2` 里可能还挂着 `editor` 标签页，甚至是当时唯一的标签页。
`stripRetiredTabs()` 在 `hydrate()` 时把这类标签页摘掉，并把 `activeTab` / `secondTab` / `cells`
指向还活着的标签页 —— 不会一开项目就撞见一个空窗（真遇到不认识的 kind，`renderPane` 也会给
一个「这个窗口已经不在了 + 关掉它」的兜底页，而不是白屏）。

宿主侧 `/fs/read` 保留（产物清单 `.wt/artifact.json` 还在用），`/fs/write`、`/git op=linemap`
保留但没有界面调用方，留给外部集成。

## ② 项目内标签条：左右滑

以前 `.tabs` 本身就能 `overflow-x: auto`，但滚动条高度被设成 0，鼠标滚轮在它上面只会滚纵向 ——
等于「看不见也滑不动」。现在：

- 溢出时两侧出现 `‹ ›` 按钮，各滚 60% 可视宽（`scrollBy` + `behavior:'smooth'`）；
- **滚轮直接横滚**：竖直滚轮映射成 `scrollLeft`。用原生 `passive:false` 监听，
  因为 React 的 `onWheel` 是被动的，`preventDefault()` 会被忽略并告警；
- 横向滚轮 / 触控板横扫本来就能滚，不拦；
- 切到一个被挤出视野的标签页 → `scrollIntoView({ inline:'nearest' })` 自动带回；
- 底部留一条 3px 细滚动条（`scrollbar-width: thin`），滑到头那侧的箭头自动置灰。

## ③ 自定义窗口：`kind:'file'` + `GET /asset`

以前只能「粘贴一段 HTML」或「填一个网址」。想用一个本地 `.html`（往往还带同目录的 css / js / 图片）
就没辙了：`srcDoc` 没有基地址，相对路径全断；`/fs/raw` 只放行媒体扩展名，`.html` 直接 415。

现在多了第三种窗口：**body 就是这个文件的绝对路径**，渲染时由宿主托管：

```
GET /api/trae-worktable/asset/<令牌>/<相对路径>
```

`<令牌>` 是**文件所在目录的 base64url**。这是关键：iframe 的文档地址变成了
`/asset/<令牌>/index.html`，页面里 `<link href="app.css">` 自然解析成 `/asset/<令牌>/app.css`，
落到同一个目录 —— 用户文件一个字都不用改。

安全上：

- 只放行网页资源扩展名（html / css / js / json / svg / 图片 / 字体 / 音视频），同目录的
  `.txt` / `.md` / `.db` 读不到（415 `not-asset`）；
- `../` 越界 403（先 `resolve` 再 `insideRoot`）；
- HTML 响应带 `Content-Security-Policy: sandbox allow-scripts allow-forms allow-modals allow-popups allow-downloads`，
  iframe 也**不带** `allow-same-origin`：脚本照跑，但页面拿不到插件接口的同源身份
  （`localStorage` 会被禁用），也就没法反过来调 `/fs/write` 改你的文件。

四个入口：

1. 自定义窗格左栏底部 `＋ 网页文件`；
2. 编辑视图里的 `选文件…`（自己画的列表：目录 + `.html/.htm`，默认从项目目录起步）；
3. 文件管理器里**双击 `.html`**；
4. 文件管理器右键 `❖ 在自定义窗口里打开`。

窗口名默认取文件名（去掉扩展名），路径必须是绝对路径（相对路径宿主解析不了，保存时直接拦下）。

## 自测

- host 176 → **188**：`/asset` 直出 html、mime、CSP sandbox、同目录 css、`.txt` 415、
  `../` 越界 403、令牌无效 400、文件不存在 404；`custom/save` 接受 `kind:file` + 绝对路径、
  拒绝相对路径、拒绝非 `.html`。
- client 599 → **585**：删掉 40 条编辑器用例（保存守卫、只读预览、行号栏、Markdown / 高亮预览），
  新增 26 条 —— 老标签页迁移、双击文本走 `/fs/open`、双击图片 / PDF 走媒体窗、
  双击 html 落自定义窗口、`htmlUrl` 的令牌拼接（同目录共用令牌、b64url 不含 `+/=`）、
  选文件列表过滤、相对路径不落库、绝对路径存成 `kind:file`。

## 升级

```powershell
& "<你的 DSH 安装目录>\resources\runtime\cli\bin\dsh.cmd" plugin --profile desktop add `
  "https://github.com/nscn6fdx44-crypto/dsh-worktable/releases/download/v0.10.6/trae-usage-worktable-0.10.6.tgz"
```

**host 和 client 都改了，必须完整退出 DSH 再重开**（只刷新界面不生效）。

要验的三件事：

1. 打开一个项目 → 标签条里**没有「编辑器」**了；双击 `README.md` 弹系统默认程序；
2. 标签页开到 6 个以上 → 标签条两侧出现 `‹ ›`，滚轮能横滚；
3. 双击一个 `index.html` → 落进「自定义」窗格并渲染出页面，同目录的 css / 图片都在。
