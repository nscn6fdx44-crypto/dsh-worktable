# Trae Worktable —— DSH 插件

DeepSeek Harness（DSH）侧边栏**工作台**插件：把你的项目收纳成侧边栏应用抽屉，提供可停靠的分栏工作区——文件浏览、真 PTY 终端、内置浏览器、媒体查看、笔记、自定义窗口（含直接挂本地 `.html`），以及完整的 git / GitHub 管理——全部在 DSH 内完成。

> 英文说明见 [README.md](README.md) · 当前版本 **0.10.7**

需要 **DSH `0.2.0-rc.2` 或 `0.2.1-rc.2`**（Windows 桌面端）。

## 安装（从 Release，推荐）

> 🔰 **不想碰命令行？** 直接看手把手教程：**[INSTALL.md](INSTALL.md)**（每一步都写了「你会看到什么」）。

无需构建。**先完整退出 DSH**（右键托盘图标 → 退出）——否则 CLI 会报错 `profile "desktop" is managed exclusively by the Electron application`。

CLI 在「你的 DSH 安装目录」下的 `resources\runtime\cli\bin\dsh.cmd`——下面命令里的路径**换成你自己的**（装在 D 盘是 `D:\dsh\...`，默认位置是 `C:\Program Files\DeepSeek Harness\...`）。

**方式 A —— 直接按网址装**（DSH 自己去 GitHub 下载附件）：

```powershell
& "<你的 DSH 安装目录>\resources\runtime\cli\bin\dsh.cmd" plugin --profile desktop add "https://github.com/nscn6fdx44-crypto/dsh-worktable/releases/download/v0.10.7/trae-usage-worktable-0.10.7.tgz"
```

**方式 B —— 下载后装本地文件**（GitHub 慢或被墙时用）：

1. 从 [v0.10.7 Release](https://github.com/nscn6fdx44-crypto/dsh-worktable/releases/tag/v0.10.7) 把 `trae-usage-worktable-0.10.7.tgz` 下载到**你想放的任意目录**
   （253.6 KB，sha256 `ec609bc94ef1621adf1fa01506b602eb7e8f952624a0b34bbab67c2f86d25b70`）
2. 在 PowerShell 执行——路径换成**你自己**存放的位置：
   ```powershell
   & "<你的 DSH 安装目录>\resources\runtime\cli\bin\dsh.cmd" plugin --profile desktop add "<你下载的完整路径>\trae-usage-worktable-0.10.7.tgz"
   ```

重开 DSH —— 侧边栏即出现「工作台」面板。用 `/api/trae-worktable/health` 核对：`"version": "0.10.7"`。

## 功能

- **项目抽屉**——从侧边栏扫描、固定、排序、管理本机项目；卡片大小按宿主实际给的空间自适应
- **可停靠分栏工作区**——窗格贴在对话左侧，右侧留给**真能打字的** DSH 对话；比例可拖、按项目记忆
- **布局预设**——六种：单栏 / 左右 / 上下 / 上一下二 / 三列 / 2×2，分割线都能拖；标签可以拖到别的格子互换
- **文件浏览**——带沙箱，拦截凭证目录（`.ssh` / `.aws` / `.env*` 等）与越界路径；文件按类型分流：媒体窗 / `.html` 进自定义窗口 / 其余交系统默认程序
- **终端**——真 PTY（xterm.js + 宿主自带的 node-pty）：`vim`、`top`、`ssh`、REPL 都能跑，`Ctrl+C` 真的进前台进程；借不到原生模块时降级为「一条命令一个进程」
- **运行配置**——一键 ▶ 把命令喂进终端（cwd = 项目目录），■ 停止，端口直接开窗格
- **内置浏览器**——在停靠窗格里打开内部工具与网页（先探测可达性与能否 iframe）
- **媒体窗**——图片 / PDF / SVG / 音视频，支持「选择文件」与「浏览项目」
- **笔记窗**——按项目的随手笔记，Ctrl+S / 失焦保存
- **自定义窗口**——生成并保存小型 HTML 工具，窗格内预览
- **产物回挂**——项目里的 `.wt/artifact.json` 会把产物自动挂进窗格
- **总览**——所有项目与宿主会话一屏尽览，支持搜索、排序、筛选、拖到侧边栏固定
- **git / GitHub**——独立「源代码管理」窗：暂存、提交、推送、拉取、分支、标签、历史与 diff；
  可登录 GitHub（本机 git 已有凭据会自动识别），把本地项目建仓上传，带实时进度克隆公开/私有仓库
- **快捷键体系**、项目模板、配置 JSON 导入导出
- **拖到对话**——文件行或网页地址拖到顶栏，自动填成一段可发送的内容

## 本版变更（0.8.48 → 0.10.7）

- **0.10.7** 从资源管理器把 `.html` **直接拖进自定义窗口**能用了，而且不再留下宿主的「文件或图片拖动到此处即可添加」
  整窗遮罩关不掉 —— 那层遮罩是**纯装饰**（`pointer-events: none`，连按钮都没有），只能由宿主自己处理 `drop` 时复位
  （从资源管理器拖进来的拖拽压根不派发 `dragend`），我们一旦把 drop 就地吃掉，它就永远挂在屏幕上，点不掉、Esc 也没用。
  现在的办法：`document` **捕获阶段**掐掉落在工作台上的 `dragenter`；万一它已经亮了，就补一发合成 `dragleave` 让它自己复位。
  顺带把预览 iframe 里的 `alert` / `confirm` 也一并禁掉了（Electron 里会把整个窗口变成模态）
- **0.10.6** 三处界面调整：① **删掉「编辑器」窗格**（和宿主 / 系统默认程序重复），文件改为按类型分流 ——
  图片/PDF/音视频进媒体窗、`.html` 进自定义窗口、其余交给系统默认程序；老版本存下的 `editor` 标签页会自动清掉。
  ② **项目内标签条能左右滑**：溢出时出 `‹ ›` 箭头、滚轮直接横滚、切到被挤出去的标签自动带回、底部细滚动条提示。
  ③ **自定义窗口能放本地 html**：新增 `kind:'file'` + `GET /asset/<目录令牌>/<相对路径>`，
  同目录的 css / js / 图片照常加载（`srcDoc` 做不到）；只放行网页资源类型、`../` 越界 403、页面在沙箱里跑
- **0.10.5** 项目名和**侧边栏上的会话名一模一样**：会话名是宿主折叠整条日志得到的（`session/title` 事件在日志开头），
  我们原来只扫尾部 400 条、冷会话连日志都读不到，于是掉到兜底的工作目录名 —— 默认工作区就叫 `default-workspace`。
  现在直接调 `sessionQuery.readTitleSnapshots` 批量取（60s 缓存），行上多一个 `titled` 标记区分「真名字 / 只是目录名」
- **0.10.4** 拖 DSH 会话进来**会自动命名**：宿主只给会话 id，现在会回查 `/sessions` 拿标题，
  先落项目、补拉一次再改名；拖到某个项目上是**绑定**到它（不再凭空多一个）；修掉 `effectAllowed=move` 与 `dropEffect=copy` 不兼容导致 drop 根本不派发的问题
- **0.10.3** 克隆仓库**可以浏览目录**：「克隆到」右边加「浏览…」，内嵌目录树逐级点选、
  `↑` 回上级、一键回填；只列子目录，读得到但写不了的路径当场亮红并禁用确认
- **0.10.2**（0.10.6 随编辑器下架）**行号栏显示 git 改动**：新增 / 修改 / 删除三种竖条 + `+n ~n −n` 统计，
  基于 HEAD 的 `git diff -U0` 最小 hunk，保存后自动重算；文件不在仓库里就不染色
- **0.10.1** 支持**取消初始化**（删 `.git`）：只删 `.git`，项目文件一个不动；
  服务端三条硬约束（要确认 / 必须在仓库根 / `.git` 必须是目录）
- **0.10.0** git 从「只读」变成完整工作流：新增**源代码管理**窗（暂存 / 提交 / 推送 / 拉取 / 分支 / 标签 /
  历史 / diff / 软回退）、**GitHub 登录**（自动识别本机已有凭据，也可粘令牌）、**把项目建仓上传**、
  **克隆仓库**（NDJSON 实时进度）。令牌不进 argv，0600 落盘；顺手修掉 8.3 短名被误判越界的问题。

- **0.9.0** 一次补掉与上游的三处差距：**真 PTY 终端**（借宿主自带的 `node-pty`，`vim` / `top` / `ssh` / REPL 都能跑，`Ctrl+C` 真的进前台进程；借不到原生模块时降级成命令模式并写明原因）、**六种布局预设**（新增上一下二、三列、2×2）、**标签跨格拖**
- **0.8.53** 拖文件 / 网页到会话：把文件管理器里的一行、或浏览器地址栏拖到工作台顶栏，路径（含标题）就填进右侧对话输入框，**不会自动发送**；工具条「→ 对话」「💬」一键同效

0.8.48 – 0.8.52 这五个版本修的都是同一族问题——侧边栏尺寸与让位几何：

- **0.8.48** 卡片改为测量宿主**实际**给的空间（`sideModeOf`），不再固定 `46vh / 330px`
- **0.8.49** 卡片不再压住宿主会话列表。真因是**溢出而非层级**：卡片禁止收缩（`flex: 0 0 auto`）导致溢出到列表上
- **0.8.50** 宿主开文件预览等重排时不再铺满整窗（`pickDock` 沿用上次几何并标 `stale`，随后重测）
- **0.8.51** 锚点彻底找不到时，降级盒子不再是 `inset: 0`，改为有界的 `is-undocked`
- **0.8.52** 侧边栏展开时不再吃掉宿主的关闭/收起键（降级盒子不再从 `x = 0` 起算）

离线自测：host **131** + client **481** 条断言全通过。

## 安全

- **防 CSRF**——仅本机 DSH（localhost）可调用插件路由，跨域请求一律 403
- **沙箱**——**写**操作限定在已注册的项目根目录，`..` 与绝对路径被拒
- **凭证保护**——`.ssh` / `.aws` / `.gnupg` / `.kube` / `.dsh` / `.netrc` / `.env*` / `.npmrc` / `.gitconfig` / `.pki` / `.azure` 均被拦截
- **SSRF 防护**——网页探测功能拒绝链路本地与云元数据地址（`169.254.*`、`fe80::`）
- **读**操作按设计**不**限于项目根（完整披露见 [dsh/README.md](dsh/README.md)）

## 从源码构建 / 开发者安装

```sh
cd dsh
npm install
npm run build      # 产出 lib/index.js + lib/client.js
npm test           # 离线自测（host 131 + client 481 条断言）
```

开发者 `link` 安装（需先完整退出 DSH）：

```powershell
& "<你的 DSH 安装目录>\resources\runtime\cli\bin\dsh.cmd" plugin --profile desktop add "link:<仓库根目录>\dsh"
```

插件源码位于 [`dsh/`](dsh) 目录。完整文档（路由、契约、踩坑、验收清单）见 [`dsh/README.md`](dsh/README.md)；交接说明见 [`dsh/HANDOFF.md`](dsh/HANDOFF.md)。
