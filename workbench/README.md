# workbench —— 单文件工作台

本仓库的**第三个产物**：把工作台压成**一个自包含 HTML** + **一个零依赖本地服务**，面向「不装扩展、不装 Skill，打开就能用」的场景。

与 `traework/` 的关系：两者功能同源（项目卡片网格 / 控制室 / 分栏工作台 / 本地服务），但形态不同。

| | `traework/` | `workbench/` |
|---|---|---|
| 数据 | Skill 管数据，`.worktable/worktable.json` | 快照数据内嵌进单文件 |
| 视觉 | 渲染管线（`render.mjs` + `lib/` 三件套） | 模板 + 运行时全内联 |
| 打开 | 需先 `npm run traework:install` 装成项目技能 | 双击 HTML 即可，无构建、无依赖 |

## 在线打开

GitHub Pages：`https://nscn6fdx44-crypto.github.io/trae-usage/workbench/`

Pages 是纯静态托管，但**零服务版支持在浏览器里扫描本机目录**：点一次「选择本机目录」即可扫描出本机项目，
结果并入项目栏与本地检索，`repo` 窗格可直接读写该目录——**不需要 Node、不需要安装**。

静态站点下自动降级为可读提示的能力：端口探测仅近似（浏览器无法枚举本机全端口，只探 27 个常见端口）、
服务端重扫、网页反代、自定义项目登记。想要完整能力就在目标机器上跑 `node serve.mjs`。

## 换机怎么用（零服务版，推荐）

1. 新机器上用 **Chrome / Edge** 打开 Pages 地址，或把 `index.html` 拷过去双击
2. 进入**控制室** → 「本机目录」区块 → 点 **「选择本机目录」**，选中项目根目录（如 `D:\projects`）
3. 浏览器端就地扫描：命中 `.git` 或任一工程标记文件（`package.json` / `CMakeLists.txt` / `Cargo.toml` / `go.mod` …）即认定为项目

目录句柄存在浏览器 **IndexedDB** 里，刷新或下次打开仍在；浏览器会把权限降级为「待确认」，点一次**「续期授权」**即恢复。

### 选择目录失败？用「兼容模式扫描」

「本机目录」区块里的这个按钮**完全不依赖目录选择器、不需要任何权限**：

- 它用浏览器的目录枚举（`<input webkitdirectory>`）拿到一份文件清单，**由页面自己在内存里重建目录树**，再按同一套规则识别项目
- `C:\` 这类系统不允许写入的位置、以及 `file://` 地址，都能照常扫描
- 代价是拿不到目录句柄：**只能只读浏览文件内容，不能写盘**，且刷新后要重新扫一次
- 想直接写盘时，再点「选择本机目录」；若连只读授权都被拒，先点「以只读方式重选」（跳过 `readwrite` 直接只读申请）

> 兼容模式**不要选整个盘（如 `C:\`）**：浏览器会先把整盘文件枚举完再交给页面，这一步拦不住、会卡很久。
> 请改选更靠近项目的父目录，例如 `C:\Users\你\Desktop\code`。

### 扫描上限与诊断

扫描有硬上限，目的是**保证任何情况下几秒内一定返回结果**，不会出现「点了没反应」：
遍历上限 2500 个目录、耗时上限 5 秒、项目上限 150 个、单项目测量上限 5 秒；超限即停并在结果行标注已截断。
遍历为**广度优先**，即使某一支体量极大（如 `AppData`）也不会吃光预算、让后面的浅层项目轮不到。
`Windows` / `Program Files` / `ProgramData` / `AppData` / `node_modules` 等 20+ 个系统与缓存目录直接跳过。

扫描期间「本机目录」区块实时显示进度（已遍历 N 个目录、最深 M 层），扫完在「扫描结果」行写明遍历统计。
选完没看到项目时先看这两行，弹窗也会给出具体原因。

## 项目栏管理

左侧「项目」栏自带两个入口：

| 入口 | 行为 |
|---|---|
| **添加** | 弹窗填名称 / 目录路径 / 语言标签，写入浏览器 `localStorage`；已连本地服务且填了绝对路径时，会调用 `POST /api/register` 把该目录登记进登记表，`repo` 窗格随即可以直接读写它 |
| **多选** | 行内出现复选框，点行即勾选；工具条提供「全选 / 清空 / 移除」。移除需二次确认，**磁盘上的文件不会被删除** |

移除只影响工作台的可见列表：自定义项从 `localStorage` 摘掉（需重新添加），扫描项记入 `wt2.removed`。
只要存在被移除的扫描项，项目栏顶部就会出现「已移除 N 个扫描项目 · 全部恢复」，一键还原。
登记表只增不删，因此恢复后 `repo` 窗格依旧可读写。

## 目录

| 路径 | 职责 |
|---|---|
| `index.html` | **产物**：公开版单文件（示例数据），Pages 入口 |
| `serve.mjs` | 本地服务：零依赖 Node，现读 HTML + 项目文件读写 API + 端口探测 + 网页反代 + 自定义项目登记 |
| `启动工作台.bat` | Windows 双击启动器 |
| `build/workbench.template.html` | 模板：结构 / 样式 / 运行时，`/*__DATA__*/` 为数据占位符 |
| `build/build.mjs` | 注入本机扫描快照生成 `workbench.html`（个人版，不入库） |
| `build/build-public.mjs` | 注入示例数据生成 `index.html` |
| `build/verify.mjs` | 静态校验：自包含 / 数据契约 / 视觉回归 / 公开版零本机标识 |
| `build/smoke.mjs` | 运行时冒烟：快照 / 服务 / 零服务 / 单项目根 / 超大根 / 兼容模式六场景 |
| `build/e2e.mjs` | 真实浏览器端到端（Edge/Chrome headless + CDP，`file://` 下真跑授权→扫描→读写） |
| `build/serve.test.mjs` | 服务端路由契约 |

## 两种打开方式

| 方式 | 命令 | 产物 | 能力边界 |
|---|---|---|---|
| 直接打开 | 双击 `index.html` | 仓库内的 `index.html` | 零服务版：快照数据 + 浏览器端扫描本机目录（需 Chrome / Edge 86+）；`file://` 下若目录选择器被拦，用「兼容模式扫描」兜底 |
| 在线打开 | 访问 Pages 地址 | 同上 | 同上；`https` 是安全上下文，原生目录选择器一般可正常授权 |
| 本地服务 | `node serve.mjs`，或双击 `启动工作台.bat` | 每次请求现读 HTML | 全能力：读写 / 端口探测 / 重扫 / 反代 |

本地服务默认监听 `7331`，被占用时自动递增；未提供 `workbench.registry.json` 时以空登记表启动，
扫描根由 `os.homedir()` 推导。

## 命令

```bash
node build/build-public.mjs       # 生成 index.html
node build/verify.mjs             # 静态校验（无个人版数据时自动只校验公开版）
node build/smoke.mjs index.html   # 六场景冒烟
node build/e2e.mjs index.html     # 真实浏览器端到端（需本机装有 Edge / Chrome，未装自动跳过）
node build/serve.test.mjs         # 服务端契约
```

## 安全边界

- `repo` 类读写一律经 `resolveWithin` 钉在已登记项目根内，`..` 与绝对路径拒绝；读取上限 512 KB、写入上限 1 MB、目录列表上限 400 项
- `POST /api/register` 只接受**已存在目录的绝对路径**（相对路径、文件路径、不存在的路径分别 400 / 400 / 404），且只增不删
- 反代剥掉 `X-Frame-Options` / CSP 等内嵌封锁头，并注入 `<base href>` 修正相对资源
- 探测同时识别 `X-Frame-Options` 与 CSP `frame-ancestors`，站点声明禁止内嵌时直接给兜底提示，不停在空白页
- 零服务模式的路径一律以扫描根 + 相对路径钉死，不落盘绝对路径

## 跨机使用

| 场景 | 是否可用 |
|---|---|
| 换电脑打开界面 | ✅ 访问 Pages 地址，或把 `index.html` 拷过去双击 |
| 扫描新机器的项目 | ✅ 零服务版：点一次「选择本机目录」即在本机扫描（浏览器端完成，无需 Node） |
| 选择目录器被拦 / 位置不允许写入 | ✅ 点「兼容模式扫描」：只枚举文件清单，不需要权限，`file://` 下也能用（只读） |
| 读写本地文件 | ✅ 同一套授权即可读写；`file://` 下若选择器被拦，改用 `https://…` 或 `http://127.0.0.1` |
| 端口探测 / 服务端重扫 / 网页反代 | ⚠️ 零服务版仅近似端口探测；完整能力需在目标机器跑 `node serve.mjs` |
| 授权跨会话保留 | ✅ 目录句柄存 IndexedDB；刷新或下次打开点一次「续期授权」（兼容模式的清单为会话级，需重扫） |

## 隐私

`index.html` 用的是**虚构示例数据**，项目路径统一为 `D:\projects\...` 占位，不含任何真实用户信息。
`build/verify.mjs` 会断言公开版不含用户名、`C:\Users\`、`LAPTOP-` 等标识，防止误传。

个人版产物（内嵌本机真实路径、别名与目录样本）为 `workbench/workbench.html` 与 `workbench.registry.json`，
两者已在仓库根 `.gitignore` 中排除，不入库。
